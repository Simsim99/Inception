Inception Stack

A simple Dockerized WordPress infrastructure.

Core Services

  • NGINX: The Web Server (Port 443)
  • WordPress: The Application Server (PHP-FPM)
  • MariaDB: The Database Server

Bonus Services

  • Redis: In-memory cache for speed
  • Adminer: Database GUI
  • FTP: File upload server
  • Portainer: Container management UI
  • Static Site: This page!
